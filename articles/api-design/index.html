API Design: Thiết kế contract trước khi viết controller

API tốt giúp các team độc lập phát triển mà không phải liên tục sửa code của nhau.

Contract phải rõ

Request, response, error format, authentication và semantics cần được xác định trước. OpenAPI có thể biến contract thành tài liệu và đầu vào cho tooling.

Backward compatibility

Client thường cập nhật chậm hơn server. Thay đổi field hiện có cần cân nhắc kỹ; breaking change nên có versioning và migration path rõ ràng.

Error cũng là API

Mã HTTP, error code và message nên nhất quán. Client cần dựa vào code ổn định thay vì parse text tự do.

Thiết kế cho người dùng API

API không chỉ tối ưu cho backend. Hãy xem xét pagination, filtering, idempotency, rate limit và observability để client có thể xây dựng ứng dụng đáng tin cậy.
