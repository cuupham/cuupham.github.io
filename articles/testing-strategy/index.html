Testing Strategy: Test đúng lớp thay vì test mọi thứ

Một hệ thống đáng tin cậy cần nhiều lớp kiểm chứng, nhưng không phải mọi logic đều cần end-to-end test.

Unit test

Unit test phù hợp với business logic nhỏ và deterministic. Chúng chạy nhanh, dễ xác định nguyên nhân lỗi và nên chiếm phần lớn test suite.

Integration test

Integration test kiểm tra ranh giới giữa các thành phần như database, HTTP client hoặc message broker. Đây là nơi nhiều lỗi cấu hình và mapping xuất hiện.

End-to-end

E2E kiểm tra hành vi từ góc nhìn người dùng nhưng thường chậm và dễ flaky. Chỉ nên dùng cho các flow có giá trị cao.

Test là tài liệu sống

Test tốt cho thấy hệ thống được kỳ vọng hoạt động thế nào. Khi behavior thay đổi, test phải thay đổi cùng production code thay vì trở thành gánh nặng.
